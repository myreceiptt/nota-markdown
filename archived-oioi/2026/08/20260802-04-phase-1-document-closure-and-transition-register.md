## 1. Closure Principle

A document is complete when its purpose, authority, version, evidence level, and future status are clear.

Historical drafts should not be rewritten merely to make earlier ideas appear correct.

---

## 2. Status Definitions

| Status | Definition |
|---|---|
| Active Authority | Current source of truth |
| Final Reference | Complete for a defined factual or architectural purpose |
| Final and Approved | Accepted for execution or institutional use |
| Implementation Pending | Approved design exists; execution is incomplete |
| Historical Artifact | Retained to document what happened |
| Archived Hypothesis | Preserved idea; not an active plan |
| Superseded | Replaced by another document |
| Preliminary Evidence | Output exists; insufficient for final approval |
| Closed | No further updates; future work uses new documents |
| Pending Founder Decision | Cannot proceed without resolution |

| Progress | Program Status Report |
| Research | Research Note |

## 6. Change Control

No document may become implementation authority without recording:

- approving decision;
- approving person or body;
- date;
- scope;
- owner;
- resources;
- legal or financial gates;
- acceptance criteria.

Silence, enthusiasm, or absence of objection is not approval.
